# 看漫画（Comic Viewer）

功能更全的漫画界面，获得更好的观看体验：图片预加载、双页无缝拼接、目录跳转、条漫连续滚动、章节自动衔接、日漫右起、缩放、本地缓存。

界面支持 **中文 / English / 日本語 / 한국어**，可在设置里随时切换。

---

## 使用方法

1. **安装 Tampermonkey 插件**  
   在浏览器扩展商店中搜索并安装 **Tampermonkey** 插件。

2. **添加新脚本**  
   安装完成后，点击浏览器右上角的 Tampermonkey 图标，选择 **“添加新脚本”**打开脚本编辑器。

3. **粘贴脚本内容**  
   打开本项目的 **Comic Viewer.js**，将其中的脚本内容完整复制，将编辑器的默认代码删除，然后刚才复制的脚本粘贴到 Tampermonkey 的脚本编辑器中。  

4. **保存脚本**  
   粘贴完成后，按 **Ctrl + S**（Mac 为 **Command + S**）保存，或点击编辑器中的 **“文件” → “保存”**。

5. **访问受支持网站**  
   保存成功后，打开本插件受支持的网站，脚本即可自动生效并使用。

> 注意：请确保脚本已启用，并且浏览器允许 Tampermonkey 在对应网站上运行。

## 功能一览

| 功能 | 说明 |
|---|---|
| **全屏阅读** | 图片上下顶格、左右无缝，没有站点的侧栏和广告位干扰 |
| **目录跳转** | 一键列出全部章节，搜索框过滤，当前话高亮并自动滚动到可见位置 |
| **章节自动衔接** | 翻到本章最后一页继续翻，直接进下一话，中间不用回目录 |
| **双页拼接** | 两张竖图紧贴成一屏，可按日漫习惯让第二页在左侧 |
| **条漫模式** | 整章图片竖排成一列连续滚动，滚到底自动接下一话 |
| **预加载** | 提前下载后面几页，翻页时基本是瞬间出图 |
| **本地缓存** | 图片存进浏览器本地数据库，回头再看不用重新下载 |
| **缩放与拖动** | 滚轮或 `+ -` 缩放，放大后可拖动画面；支持原始像素查看 |
| **续读** | 记住上次读到哪一话第几页，下次打开接着看 |
| **四种界面语言** | 中 / 英 / 日 / 韩，首次打开跟随浏览器语言 |

## 打开阅读界面

两种方式，效果一样：

- 点左下角的**入口按钮**（在作品页显示「阅读」，在阅读页显示「看图」）
- 按键盘 **`V`**

从**作品页**打开：从第一话第一页开始（如果之前读过，会接着上次的位置）。
从**阅读页**打开：从这一话的第 1 页开始；E-Hentai 因为一页一个地址，会直接从你当前看的那一页开始。

## 界面速览

### 顶栏（默认收起，点画面正中显示 / 收起）

从左到右：

| 元素 | 作用 |
|---|---|
| 标题 | 作品名 |
| 章节标签 | 当前章节名 + 第几话/共几话（只有多话的作品才显示） |
| **适应 / 宽度 / 原始** | 三种缩放方式，见下 |
| 目录图标 | 打开章节列表 |
| 条漫图标 | 开关条漫模式（快捷键 `W`） |
| 双页图标 | 开关双页模式（快捷键 `S`） |
| 单页图标 | 单页步进校准（快捷键 `1`） |
| 明暗图标 | 深色 / 浅色界面（快捷键 `T`） |
| 齿轮 | 设置面板 |
| × | 关闭阅读界面（`Esc`） |

**三种适配方式：**

- **适应**：整组图片缩放到刚好装满可视区，不裁切。长图（条漫）只缩不放，比屏幕窄就居中留白。
- **宽度**：铺满屏幕宽度，会放大，一屏看到的内容更少。
- **原始**：按图片原始像素显示，装不下就出现滚动条，可用鼠标拖动画面。

### 底栏

- 左边：**页码**，例如 `15–16 / 120`（双页时显示两页）
- 右边：**进度条**。每一格代表一页，已缓存的格子颜色更深，可以直接点某一格跳过去。
  章节超过 240 页时改成一条整体进度条。

### 鼠标 / 触屏

- 点画面**左 1/3**：上一页；点**右 1/3**：下一页；点**正中**：显示 / 收起工具栏。
- 左右方向可以在设置里对调（「点击翻页（下一页）」）。
- 放大后按住拖动可以平移画面。
- 滚轮默认翻页，也可以改成缩放。

## 设置项

点顶栏齿轮打开。所有设置都会记住，下次打开沿用。

| 设置 | 默认 | 说明 |
|---|---|---|
| **界面语言** | 跟随浏览器 | 中文 / EN / 日本語 / 한국어 |
| **条漫模式（整章连续滚动）** | 关 | 打开后整章铺成一列连续滚动；与双页模式互斥，开一个会自动关另一个 |
| **双页模式** | 关 | 两张竖图拼成一屏 |
| **日漫模式（第二页在左）** | 开 | 仅双页时有效。日漫从右往左读，第二页排在左侧 |
| **预读取页数** | 4（1–8） | 不建议开太大，一些网站可能会因此封禁ip |
| **缓存页数上限** | 120（2–500） | 本地最多保留多少张图，超出后自动淘汰**最旧的** |
| **图片缓存** | 开 | 关掉则不往本地存图，每次都从网络取 |
| **已缓存 / 清空缓存** | — | 显示当前占用（张数 · 体积），可一键清空 |
| **点击翻页（下一页）** | 右边 | 点哪一侧是「下一页」。习惯左侧前进就切到「左边」 |
| **单页步进（校准）** | 关 | 见下方「双页对不齐怎么办」 |
| **鼠标滚轮** | 翻页/放大 | 可改为「放大」。改后滚轮直接缩放，翻页用键盘或点击 |

### 双页对不齐怎么办

- **单页步进（校准）**：打开后每按一次翻页只走一页，用来逐页找到合适的起点；找到后关掉，继续按双页翻。

## 条漫模式

适合竖条漫。

- 打开后整章图片竖排成一列，像站点自己的阅读页那样连续滚动。
- 滚到底部附近，自动把**下一话**接到列尾，中间不用手动切章。
- 翻页键变成「向下滚一屏」。

> 条漫模式会一次性把整章图片排进页面（图片本身仍按需加载），超长章节（几百页）内存占用会比较高。遇到卡顿可以切回单页模式，或把「缓存页数上限」调小。

## 缓存与本地数据

脚本只在你的浏览器本地存东西，**不会上传到任何服务器**。

| 存什么 | 存在哪 | 说明 |
|---|---|---|
| 图片字节 | IndexedDB `cmv-images` | 键是**去掉 `?` 参数后**的图片地址，所以带时效 token 的链接也能命中缓存 |
| 阅读进度 | localStorage `cmv:pos:*` | 每话读到第几页 |
| 章节列表 | localStorage `cmv:list:*` | 12 小时后过期，过期会重新抓 |
| 设置 | localStorage `cmv:config` | 上面那些设置项 |

## 常见问题

**Q：打开后左下角没有按钮？**
- 确认当前页面是作品页 / 画廊页 / 阅读页，不是搜索页或首页。
- 刷新一次页面。
- 检查用户脚本管理器里这个脚本是不是被禁用了。

**Q：点开只显示一个空白界面？**
通常是章节列表没读到（站点改版或页面还没加载完）。等页面完全加载后再按 `V` 试一次。

**Q：手机上能用吗？**
暂不支持。

**Q：会不会影响站点本身的功能？**
阅读界面是覆盖在页面上的一层，关掉就恢复原样。脚本只拦截了方向键 / 空格等导航键，避免翻页时页面跟着滚动。

## 权限说明

脚本头部声明了两项需要你知道的权限：

- `@grant GM_xmlhttpRequest` + `@connect *`
  用来跨域下载图片并写进本地缓存。**它只会请求站点自己给出的那些图片地址**，不会把数据发到别的地方。

- 脚本不收集、不上传任何个人信息，没有统计、没有远程配置、没有广告。
